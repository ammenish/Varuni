# Definition of Done

A feature is complete only when:
- It has a documented requirement and user flow.
- It has loading/empty/error/offline/permission states.
- It is keyboard and reduced-motion accessible.
- It has authorization checks server-side.
- It has audit requirements defined.
- It validates data and geometry.
- It has tests.
- It has observability.
- It has rollback behavior.
- It has provenance for analytical outputs.
- It has dependency/data/model license checks.
- It has security review appropriate to risk.
- It does not expose sensitive geospatial or personal data by default.
